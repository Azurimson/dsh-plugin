# 更新日志

本项目遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## v0.1.0 — 2026-10-29

首个公开版本。

### 新增

- **模型工具（5 个）**：`memory_write`、`memory_recall`、`memory_forget`、`memory_consolidate`、`memory_review`
- **斜杠命令（3 个）**：`/memory-list`、`/memory-review`、`/memory-consolidate`
- **遗忘曲线**：记忆强度随时间按负加速曲线衰减
- **六维重要性评分**：有意义 / 有结构 / 具体 / 自我相关 / 独特 / 有情绪，外加「记忆时长」因子
- **间隔重复与间隔效应**：同一事件间隔越久再次被提起，加深越多
- **巩固**：把高价值情节记忆合并提炼成语义记忆，原文归档
- **主动复习**：列出临近遗忘的记忆
- **纯本地存储**：所有记忆存在单个 JSON 文件，不联网、不依赖云端数据库
- 纯 ESM JavaScript，无构建步骤

### 版本行为说明（重要）

当前版本**没有自动抓取对话的机制**。记忆只在模型调用 `memory_write` 时产生。

- 你说「记住：…」是最强的触发信号，模型几乎一定会写。
- 即使不说，模型看到工具描述里写着「重要信息应主动调用」，可能会自己判断写入——但**不保证、不可控**。

也就是说，这个插件提供的是「记忆的存储、衰减与检索模型」，并不负责自动记录每一次对话；「记住什么」的主动权在模型手上。

### 已知限制

- 语义相关度使用字符 n-gram 相似度，尚未接入 embedding（向量）模型，长文本语义匹配不够准
- 巩固的合并是规则式的（拼接 + 去重），尚未接入 LLM 做摘要提炼
- 自动复习的触发方式（由 DSH 主动 / 仅用户命令触发）尚未定案
