# 迭代方向：用户画像记忆（User Portrait Memory）

> 本文只记录**未来可能开发**的功能与设计取舍，不代表当前版本已实现。
> 当前版本（0.1.2）已实现：事实记忆、行为记忆、工作记忆、遗忘曲线、间隔重复、巩固、设置卡片。

## 1. 目标

从长期对话中，逐步提炼用户的**稳定特征**，形成「用户画像」记忆：

- **口癖 / 常用词**：如「其实」「说实话」「说白了」「搞一下」。
- **句式习惯**：短句为主 / 长句展开；喜欢先结论后解释，还是先铺垫后结论。
- **逻辑习惯**：偏好举例、偏好对比、偏好直接给方案。
- **沟通偏好**：希望详细还是简洁；是否喜欢反问；是否接受英文术语。
- **关注领域与目标**：反复出现的项目、技术栈、长期目标。

画像不是「记一条事实」，而是**跨会话、缓慢收敛的统计 + 归纳**。

## 2. 为什么单独做一个「层」

现有三层（情节 / 语义 / 核心）+ 工作记忆，解决的是「发生了什么、是什么、多重要」。

用户画像解决的是「**这个人是谁、怎么跟他说话**」，特征不同：

| 维度 | 事实/行为记忆 | 用户画像 |
|------|--------------|----------|
| 来源 | 单轮/单事件 | 长期多轮统计 |
| 变化速度 | 快 | 极慢（逐渐收敛） |
| 遗忘 | 会衰减 | 几乎不遗忘（稳定特征） |
| 用途 | 回忆事实 | 调整回复风格 / 个性化 |
| 存储 | `memories/*` | 建议单独 `portrait/` |

因此建议新增一个 **画像层（portrait）**，与现有记忆库并列，而不是塞进 episodic。

## 3. 数据表示（草案）

```jsonc
{
  "id": "portrait-verbosity",
  "type": "style",              // style | phrase | logic | interest
  "label": "偏好简洁",
  "value": 0.8,                 // 0..1 倾向强度
  "confidence": 0.6,            // 置信度（随证据增加而上升）
  "evidenceCount": 12,          // 支持该结论的用户发言条数
  "examples": ["直接说重点", "别展开"],  // 少量原文证据（可关闭）
  "firstSeenAt": 1793000000000,
  "lastUpdatedAt": 1793300000000
}
```

## 4. 实现路径（分阶段）

### 阶段 1：启发式统计（不依赖 LLM，先跑通）

- 采样：只取 `user/message`（跳过注入/系统消息）。
- 统计：
  - 平均句长、问句比例、感叹号/省略号频率；
  - 高频词 / 口头禅（去停用词后取高频 n-gram）；
  - 是否常带「吗/呢/吧」等语气词。
- 输出：低置信度的 style 条目（如「句长偏短」「常用『其实』」）。
- 触发：每 N 轮或每 M 条用户发言更新一次，避免频繁写盘。

### 阶段 2：LLM 归纳（更准，但成本更高）

- 把最近一批用户发言（脱敏、截断）交给 `ctx.llm`，要求输出**结构化画像**：
  - 只允许输出有证据的结论；
  - 每条结论附 1–2 条原文证据；
  - 不确定就不输出。
- 合并：新结论与旧画像做置信度加权合并，避免被单次异常发言带偏。

### 阶段 3：消费画像

- **注入**：在系统提示词或 `agent/pre-step` 里注入「用户偏好：简洁、先结论」等，影响回复风格。
- **开关**：用户可在 `settings.json` 关闭「用画像调整回复」。
- **展示**：设置卡片里增加「用户画像」分组，可查看/删除单条画像。

## 5. 与现有机制的关系

- **遗忘曲线**：画像条目**几乎不衰减**（`tauMs` 很大或 `decay=false`），因为它描述稳定特征。
- **间隔重复**：画像不靠「再次提起」强化，而靠**证据累积**（`evidenceCount` / `confidence`）。
- **巩固**：不参与 episodic→semantic 合并，单独维护。
- **工作记忆**：画像的原始证据可先放工作记忆，定期归纳后清理，避免膨胀。

## 6. 隐私与边界（重要）

- **全部本地**：画像只存本地，不上传。
- **可关闭**：`settings.json` 提供 `portrait.enabled`，默认关闭或首次询问。
- **可删除**：设置卡片支持逐条删除、一键清空。
- **不过度推断**：只记录「可观察的语言习惯」，不推断敏感属性（健康、政治、宗教等）。
- **证据最小化**：`examples` 可配置为不保存原文，只存统计值。

## 7. 开放问题

1. 画像更新频率：每轮 / 每 N 轮 / 空闲时？
2. 画像冲突：新旧结论矛盾时，是覆盖还是保留两个并标时间？
3. 跨项目：不同项目下用户风格可能不同，是否需要「按项目分画像」？
4. 多用户共用一台机器时，如何区分用户？（当前按 `DSH_HOME` 单用户假设）
5. 是否要把画像注入系统提示词，还是只作为 `memory_recall` 的可选结果？

## 8. 明确不做

- 不做情绪识别/心理画像。
- 不做跨设备同步。
- 不把画像用于广告或推荐。
- 不在未经用户同意时把原文证据写盘。
