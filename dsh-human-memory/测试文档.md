## 5. 边界与异常

| 编号 | 场景 | 预期 |
|------|------|------|
| X1 | 空字符串内容 | 正常写入（或按需拒绝），不崩溃 |
| X2 | 超长内容（数千字） | 正常写入，`importance.uniqueness` 饱和 |
| X3 | 含换行 / 引号 / emoji 的内容 | 正常存储与召回（JSON 转义正确） |
| X4 | 数据文件被占用或损坏 | 插件告警并从空记忆开始，不崩溃 |
| X5 | 并发写入（多会话同时写） | 单线程 event loop 串行，不丢记录 |
| X6 | 会话中途 DSH 被强杀 | 未落盘的最近 5 秒改动可能丢失（已知限制） |

## 7. 已知限制（不覆盖项）

- **自动自查是启发式**：用关键词 + 长度 + 提问/问候过滤，不是 LLM 语义判断，可能漏记或误记；可用 `autoCapture` 调阈值或关闭。
- **语义相关度**用字符 n-gram，未接 embedding，长文本/同义改写匹配不够准。
- **巩固**是规则式拼接，未接 LLM 摘要。
- **批量落盘**默认 5 秒，强杀会丢最近改动；需要立即持久化可把 `storage.syncWrite` 设为 `true`。
- **跨安装不共享**：记忆绑定 `DSH_HOME`；不同 profile/安装若 `DSH_HOME` 不同则各自独立。
